# bmad-agents-game

Use one of these game role skills:

- `bmad-agent-game-architect`
- `bmad-agent-game-designer`
- `bmad-agent-game-dev`
- `bmad-agent-game-qa`
- `bmad-agent-game-scrum-master`
- `bmad-agent-game-solo-dev`

If unsure, start with `bmad-agent-game-designer` for design, `bmad-agent-game-dev` for implementation, and `bmad-agent-game-qa` for testing.
